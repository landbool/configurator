КРИТИЧЕСКИЙ РЕГЛАМЕНТ ЧЕРТЕЖЕЙ ДЛЯ ВСЕХ СЕРИЙ (GIST HEAD ONLY, NO INLINE SVG):
Категорически запрещено инлайнить SVG-чертежи в код HTML/JS или создавать строковые SVG-константы фолбэков. Правило действует абсолютно для всех серий (GR, GF, GK, GS) и любых новых серий, добавляемых в будущем. Размер HTML файлов строго поддерживается легковесным (~450-480 КБ). Все чертежи загружаются динамически исключительно по прямым Raw-ссылкам GitHub Gist в формате HEAD. При обновлении чертежа в Gist он обязан автоматически и сразу обновляться на сайте без изменения кода конфигуратора.
